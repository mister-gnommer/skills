# act-as-author

User is probably working on some changes. User may specify what those changes are exactly, if not then just check changes on current branch (and not staged and not commited). After familiarazing yourself with changes you are to act as author of this changes answering questions to the best of your knowledge and abilities. User may grill you, but do not make changes until ask directly (you may propose fixes and improvements when you see it during conversation).
